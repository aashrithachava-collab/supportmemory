# SupportMemory AI

An AI-powered customer support agent that remembers customer history,
previous issues, successful solutions, and preferences using persistent
memory.

## Problem

Customers often have to repeat their previous issues every time they
contact customer support.

## Solution

SupportMemory AI remembers previous customer interactions and uses that
memory to provide personalized support.

## Core Workflow

Customer → AI Support Agent → Hindsight Memory → Personalized Response
→ Resolution → Memory Update

## Technology

- Hindsight
- LLM
- Python
- React
